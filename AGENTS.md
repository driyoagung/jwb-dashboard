# Instruksi agent untuk repository ini

Sebelum membuat atau mengubah halaman dashboard, baca [`.agent/README.md`](.agent/README.md) dan dokumen terkait di [`.agent/docs/README.md`](.agent/docs/README.md). Gunakan komponen Blade, pola CSS, ikon, dan modul JavaScript Kenanga Admin yang sudah tersedia. Jangan membuat komponen UI baru atau merancang ulang elemen dashboard secara manual. Referensi rinci serta contoh render berada di `docs/` dan `resources/views/showcase/`.

Untuk fitur backend, ikuti [konvensi kode Laravel](.agent/docs/standar/konvensi-kode.md) dan [panduan data besar](.agent/docs/implementasi/data-besar.md).

Sebelum mengubah route privat atau fitur data, baca [referensi CRUD nyata](.agent/docs/implementasi/referensi-crud.md), [kontrak role](.agent/docs/standar/kontrak-role.md), [matriks komponen](.agent/docs/fondasi/matriks-komponen.md), dan [kriteria selesai](.agent/docs/standar/kriteria-selesai.md).

Setelah setiap task yang mengubah repository, sertakan satu usulan commit message Conventional Commits dalam satu kalimat bahasa Inggris. Untuk PR, gunakan [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) dan ikuti [konvensi commit/PR](.agent/docs/standar/git-dan-pr.md).
